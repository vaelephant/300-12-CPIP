### 04 · 临床场景

**眉题** CLINICAL SCENARIO · 临床场景

**标题** 同一术后异常事件，三种系统的响应方式不同

**场景** HCC 术后康复阶段 / 新检验结果触发医院审核过的异常规则

| 系统 | 动作 | 输出 |
| --- | --- | --- |
| 传统路径 | 记录路径变异 · 标记异常任务 · 记录偏离原因 · 等待人工处理 | 变异记录 |
| 传统 CDSS | 匹配异常规则 · 展示风险与证据 · 提醒医生复核 | 决策提示 |
| 我们的平台 | 更新患者状态 · 联动 CDSS 与受影响任务 · 生成候选计划并记录反馈 | **待审核的可追溯新路径** |

**免责** 虚构场景，仅说明产品交互；不构成诊疗建议，实际调整由医生确认。

### 05 · 首条路径

**眉题** PATHWAY · 首条路径

**标题** 从入院到院外随访，建立连续的肝癌诊疗过程

1. **入院与术前评估** — 诊断、分期、肝功能 · 手术风险及可切除性评估
2. **治疗方案确认与手术** — 医生审核 · 手术记录、术中事件、病理
3. **术后康复与出院** — 指标监测、并发症管理 · 出院评估及随访计划
4. **长期随访** — 复查与异常监测 · 复发评估及再治疗转介

**注** 标准路径由医院专家审核；系统不自主决定治疗或下达医嘱。

### 09 · 临床安全边界

**眉题** SAFETY BY DESIGN · 临床安全边界

**标题** AI 不替医生做决定，系统替医生守住边界

**副标** 高亮不是「模型多聪明」，而是每个建议都可解释、可拒绝、可追溯。

1. **真实时间轴** — 事件时间与录入时间分列 · 缺失不补造
2. **三值规则** — 未知 = UNKNOWN，不通过；排除与安全条件未知必须阻断
3. **对象级授权** — 患者、科室、角色逐层校验；越权返回 403 并留痕
4. **人工审核** — 计划必须由非提交人审核、绑定执行指纹后才能激活
5. **审计与重评** — 成功业务与审计同事务；状态变化触发重评而非自动改治疗

**注** HCC-CIP 仍为研发演示；临床签署已启动优先规则审阅，完整签署、真实数据合规、器械注册与生产环境验证为独立门槛 / 期权。

### A2 · 数据资产与飞轮

**眉题** DATA · 数据资产与闭环

**标题** 把已有肝癌病例转换为可追溯的高质量专病数据集

**四类资产**

1. **临床与影像** — 病历、检验、CT/MRI · 统一患者索引、时间戳、单位与来源
2. **围手术期与病理** — 治疗事件、手术记录、病理 · 干预前后状态及结局标签
3. **随访与生存结局** — 复查、复发、生存状态 · 观察窗口及删失
4. **路径事件数据** — 活动、时间、病例标识 · 支持流程挖掘与执行反馈

**飞轮** 临床观测 → 患者状态 → 决策与规划（CDSS / CPIP） → 医生确认执行 → 结局反馈  
经数据工厂 / 知识工厂 / 模型工厂离线治理后，经审核的知识与模型版本回流。

**硬约束** 模型更新必须离线验证、专家审核、版本发布；不允许未经验证的在线自动更新。  
最常见的历史路径不等于最优路径；挖掘结果不能直接替代医学判断。

**页脚** DR.SeeK · A2

### A3 · 知识与推理 CDSS

**眉题** KNOWLEDGE AI · 知识与推理

**标题** 将指南、医学本体与规则编译为可审计的专病 CDSS

**注** LLM 用于抽取与解释；硬性安全规则由确定性引擎执行，缺失信息进入人工复核。

**链路** 知识输入（指南 / 共识 / 院内规范） → KEE 知识工程（实体关系 / 证据 / 版本） → RAG + 规则（检索证据 / 条件校验） → 决策支持（候选建议 / 风险 / 依据）

**三道闸**

- **证据溯源** — 每条建议绑定指南版本与证据
- **安全门控** — 禁忌、缺失值、冲突规则拦截
- **医生审核** — 确认后才进入正式路径

**页脚** DR.SeeK · A3

### A4 · 路径执行内核

**眉题** EXECUTION ENGINE · 路径执行内核

**标题** 条件分支、阻断与审批，都能被解释和追溯

1. **条件边** — TRUE / FALSE / UNKNOWN 由冻结规则上下文判定；未知不默认 FALSE
2. **未选分支** — 不生成可执行任务，画布以虚线弱化；决策轨迹保留
3. **执行 trace** — 记录快照、规则版本、边、结果与原因，确定性重放
4. **审批指纹** — `execution_fingerprint` 绑定审批；trace 篡改返回 409

### A5 · 规划与世界模型路线

**眉题** PLANNING · 约束规划与世界模型

**标题** 将知识、患者状态与预测结果转化为可审核的候选路径

**当前（V0.6.1）** 患者状态 + 临床知识 + 医生确认的目标 → Pathway Planner（条件分支 · 任务依赖 · 时间窗口 · 约束校验）→ 候选路径 A/B → 人工审核（确认 / 修改 / 拒绝）

**后续研究 · MWM** 从当前状态预测未来状态：`Pθ(sₜ₊₁ | sₜ, aₜ, Δt)`  
研究目标：概率状态转移与不确定性估计；真实治疗因果效果需独立研究验证。

**硬边界** 预测驱动的多路径优化属于后续研究，不自动下达医嘱；`clinical_use = false`。

**页脚** DR.SeeK · A5

### A6 · 模型训练与验证门槛

**眉题** MODEL FACTORY · 模型训练与验证

**标题** 先建立可解释基线，再逐步训练多模态时序模型

**流水线** 数据治理（患者级去重 / 标签 / 时间窗） → 基线模型（LightGBM / Cox / Logistic） → 时序模型（GRU / 概率状态空间） → 验证发布（校准 / 外部验证 / 版本）

**方法论指标（非本演示性能宣称）**

- 分类：AUROC / AUPRC / 灵敏度
- 生存：C-index / 时间依赖 AUC
- 概率：Brier score / 校准曲线

**门槛** 所有模型须完成数据授权、患者级划分、时间外验证、校准与专家评审后方可进入临床试点。

**页脚** DR.SeeK · A6
