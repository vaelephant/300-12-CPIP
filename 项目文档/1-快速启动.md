# 1 · 快速启动

HCC-CIP（肝癌全病程智能诊疗平台）本地跑通说明。  
当前为**研发演示**：合成数据、不连接真实医院、不构成临床决策依据。

---

## 环境要求

| 项 | 版本 |
| --- | --- |
| Node.js | ≥ 20.19（推荐 22 / 24） |
| Python | ≥ 3.11 |
| 包管理 | npm（前端）、pip（后端） |

可选：`make`（根目录有常用快捷命令）。

---

## 两种运行方式（先选一种）

| 模式 | 适合 | 前端配置 | 是否需要后端 |
| --- | --- | --- | --- |
| **Demo（默认）** | 看界面、演示路径/可视化 | `VITE_HCC_API_MODE=demo` | 否 |
| **Server** | 联调真实 API、登录 JWT、患者/任务等已接入页 | `VITE_HCC_API_MODE=server` | 是（`:8000`） |

多数日常 UI 演示用 **Demo** 即可；要验证后端闭环再开 **Server**。

## A. 最快：只跑前端（Demo）

```bash
cd front
npm install
cp .env.example .env   # 可选；默认已是 demo
npm run dev            # http://127.0.0.1:5173
```

浏览器打开 → 登录页选演示角色进入（密码预填 `cpip-demo`，Demo 模式不校真实密码）。

## B. 前后端联调（Server）

### 1. 启动后端（SQLite）

```bash
cd back
python3 -m pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
python3 -m app.seed
lsof -t -i :8312 | xargs kill -9 && clear && python3 -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8312
```

- API：`http://127.0.0.1:8000/api/v1`
- Swagger：`http://127.0.0.1:8000/api/docs`
- 健康检查：`GET http://127.0.0.1:8000/api/v1/health`
- 本地库文件：`back/hcc-cip.db`（已 gitignore）

后端演示密码统一：`cpip-demo`（工号见上表）。

重置本地库：

```bash
cd back
rm -f hcc-cip.db
alembic upgrade head
python3 -m app.seed
```

### 2. 启动前端（指向后端）

```bash
cd front
cp .env.example .env
```

编辑 `front/.env`：

```env
VITE_DATA_MODE=server
VITE_HCC_API_MODE=server
VITE_HCC_API_URL=http://127.0.0.1:8000/api/v1
```

```bash
npm install
lsof -t -i :8312 | xargs kill -9 && clear && npm run dev   # http://127.0.0.1:5173
```

> 改 `.env` 后需**重启** Vite 才生效。

### 3. 已接入后端的页面（Server 模式）

登录、患者中心/详情、路径库、任务中心、规划页等走真实 API；其余部分页面仍可能用合成数据（迁移中）。详见 `front/README.md`「V0.6 前端接入状态」。

## 常见问题

**端口占用**  

- 前端默认 `5173`，后端 `8000`。改端口时同步改 `back/.env` 的 `HCC_CIP_CORS_ORIGINS` 与 `front/.env` 的 `VITE_HCC_API_URL`。

**Server 模式登录失败 / 空白患者**  

- 确认后端已 `seed` 且健康检查通过；前端 `.env` 为 `server` 且已重启 Vite。

**CORS 报错**  

- 检查 `HCC_CIP_CORS_ORIGINS` 是否包含当前前端 origin（含 `127.0.0.1` 与 `localhost`）。

**Demo 与 Server 数据不一致**  

- 正常：Demo 用 `front/src/data` 合成集；Server 用 SQLite 种子。不要混着对比病例 ID。

**Python / Node 版本不对**  

- 后端需要 Python ≥ 3.11；前端需要 Node ≥ 20.19。
