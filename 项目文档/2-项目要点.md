专病深度（肝癌）× 可运行闭环 × 可审计工程 × 医院能接上

临床路径是以治疗为核心的全流程规范，比单纯「治疗流程」更宽——还包含评估、决策节点、护理、随访和变异管理

**临床路径是医院（尤其是专科）做出来的标准诊疗模板，不是软件自动生成的。**

## 怎么做出来的（常见流程）

1. **定病种与范围**

   例如「肝细胞癌 · 肝切除围术期 + 术后随访」，不先铺所有治疗方式。
2. **找依据**

   国家/学会指南、共识、本院既往路径、病案与质控数据，抽成可执行节点与规则。
3. **临床专家起草**

   肝胆外科主导，联合麻醉、护理、影像、检验、医务处：画阶段、节点、角色、时间窗、分支条件（如 ICG、凝血）。
4. **院内评审发布**

   医务处/路径管理委员会审核 → 定版发布；之后改动通常要**新版本**，旧版冻结。
5. **试运行与修订**

   小范围试用，看入径率、完成率、变异原因，再改节点和规则。

在你们系统里对应大致是：路径设计器画图绑规则 → 校验 → 提交审核 → 医务处发布 → 患者入径执行。

## 需要什么条件

| 条件 | 为什么需要 |
|------|------------|
| **明确病种与首条路径边界** | 否则节点和规则无从定 |
| **临床专家负责人** | 阈值、分支、安全阻断必须医生定，不能靠工程师猜 |
| **指南/证据可引用** | 路径要说得出「依据是什么」 |
| **医院治理（医务处审批）** | 发布权、变更权，避免科室私改 |
| **可结构化的数据** | 分期、肝功能、检验等能进规则；大量自由文本很难入径 |
| **与 HIS/流程可衔接（真上线时）** | 任务、检验、医嘱要能对上，否则只是纸面路径 |
| **变异与质控约定** | 偏离怎么记、谁重规划，否则执行会散掉 |

**一句话**：临床路径靠「专科共识 + 证据 + 院内审批」做成；软件只是把这套模板变成可设计、可入径、可执行、可审计的东西。没有专家审过的规则，系统里的路径只能当演示，不能当临床标准。



不是「医院完全没有路径」，而是很多路径停在文档/清单，缺的是可入径、可执行、可审计、可按患者状态动态调整的闭环。
