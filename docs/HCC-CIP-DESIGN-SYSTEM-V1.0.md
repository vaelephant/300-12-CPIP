# HCC-CIP Design System V1.0
## 前端视觉与临床可视化设计规范

日期：2026-11-26。状态：设计规范提案，待实施与视觉验收。适用 HCC-CIP 全部前端页面。仅文档，不修改业务代码。

## 1. 设计哲学
Minimal. Clinical. Intelligent. 极简、专业、智能。
参考 Apple 的留白、Linear 的信息秩序、专业临床工作站的高效操作。扁平、无渐变、无装饰性发光、少阴影、细边框。临床事实优先于装饰，AI 建议不得伪装成事实或医嘱。保留 React/Vite/Tailwind/shadcn/ui/React Flow/ECharts，不另建框架。

## 2. Design Tokens
以下为建议初始值，实施时映射现有 CSS 变量，不在业务组件中散布硬编码色值。

| Token | Light | Dark（后续可选） | 用途 |
|---|---|---|---|
| canvas | #F7F8FA | #18181B | 页面背景 |
| surface | #FFFFFF | #202024 | 工作区 |
| surface-muted | #F4F4F5 | #27272A | 次级区域 |
| foreground | #18181B | #FAFAFA | 正文 |
| muted-foreground | #71717A | #A1A1AA | 辅助文字 |
| border | #E4E4E7 | #3F3F46 | 分隔线 |
| primary | #18181B | #FAFAFA | 普通主操作 |
| primary-foreground | #FFFFFF | #18181B | 主按钮文字 |
| brand | #C63538 | #F87171 | 品牌小面积点缀 |
| focus | #2563EB | #93C5FD | 键盘焦点 |

浅色优先；深色不列入本期验收。建议中性色占绝大部分，红色品牌点缀约 2%，非强制像素比例。危险色不得用于普通按钮或导航选中。

### 临床语义色（浅色）
| 语义 | 前景 | 浅背景 | 冗余标识 |
|---|---|---|---|
| 已完成/正常（分别定义） | #15803D | #F0FDF4 | check + 明确文字 |
| 执行中 | #2563EB | #EFF6FF | progress + 文字 |
| 待处理/关注 | #B45309 | #FFFBEB | clock/alert + 文字 |
| 高风险/阻断 | #B91C1C | #FEF2F2 | alert + 文字 |
| 未知/缺失 | #71717A | #F4F4F5 | question + 文字 |
| AI 建议/预测 | #7C3AED | #F5F3FF | AI 标签 + 来源 |
| 未选路径 | #71717A | #F4F4F5 | 虚线 + 未选择 |

任务完成不等于疾病正常；未测不等于阴性；风险等级、任务状态、审批状态、数据来源分别建模，禁止共享枚举导致误读。风险色优先于品牌色。正文对比度目标 WCAG AA 4.5:1，大文字与必要非文本控件 3:1，实际逐项测量；边框不足以单独表达焦点。色盲模式下文字、形状、线型仍可辨认。

## 3. 排版与尺寸
中文 PingFang SC / Noto Sans SC / 系统 sans-serif；英文 Inter（已具备授权和本地资源时）或系统字体；数字 tabular-nums。默认不加载外部字体服务。
页面标题 24/32px 600，模块标题 16/24px 600，正文 14/22px，紧凑表格 13/20px，辅助文字 12/18px；不得把重要临床信息缩小为装饰性小字。
间距 4/8/12/16/24/32；卡片圆角 8，按钮 6；边框 1px；图标 Lucide 16–20；表格行高 40–48；普通按钮高度 36，触屏关键操作建议 44。动画 120–180ms，尊重 reduced-motion。避免全屏卡片堆叠。

## 4. 工作空间布局
顶栏 52px（品牌、搜索、环境、账户）；左栏 216px，可折叠至 56px；中间自适应；右侧智能面板 320px，可关闭/调整，非每页强制显示。内容区 padding 24，紧凑模式 16。
1440px 及以上可三栏；1280–1439 优先折叠右栏；更窄时左栏折叠、智能面板抽屉化。表格/路径画布局部滚动，不让整页横向溢出。患者身份、当前状态、风险与数据环境在临床工作区持续可见。
导航分临床工作、智能分析、系统管理。保留现有路由，未来 AI/KEE/MWM 未接入时明确标注不可用；Server 模式不显示 mock 结果。Demo 全局持续标识 SYNTHETIC / 非临床使用。

## 5. 临床可视化
### 5.1 PathwayGraph（React Flow）
节点建议宽 160–220、高 48–72，细边框、左侧状态标识、简洁文字；START/END 小型圆角节点，DECISION 菱形或明确决策标签，任务矩形。正交连线，优先稳定 DAG 布局；可评估现有布局能力，不强制引入依赖。已执行实线、未选虚线、当前节点蓝色描边、UNKNOWN 琥珀色阻断标签；高风险红色。节点/边以服务端 execution_trace 为准，不由前端推断临床规则。设计态与执行态区分；缩放、适应画布、定位当前节点、详情侧栏、键盘操作及等价列表视图。展示图版本、审批、快照时点、规则版本、分支原因。禁止力导向布局、无意义动画。
### 5.2 PatientTimeline（ECharts 或轻量 SVG）
按真实时间坐标分诊断、影像、检验、治疗、随访泳道；支持范围缩放、事件聚合与展开、来源及事件时间/录入时间区分。缺失时间单独列示，不虚构时间。当前时点中性竖线，红色仅用于风险。选择事件联动指标与详情，历史回放明确 as_of，禁止未来数据泄漏。
### 5.3 LabTrendChart（ECharts）
统一单位、真实时间间隔、测量点、治疗事件标记；参考区间取 LIS/检测方法/适用人群，缺失不绘制。缺测断线，不填零，不默认平滑；单位变化不可直接连线。变化方向不自动等于改善/恶化。显示来源、时间、异常标记、原始数值；支持表格替代。
### 5.4 StateEvolution / PredictionBand
历史观测实线，预测虚线，当前时点竖线；不确定性区间仅在模型提供明确统计含义时绘制并标注区间类型/水平。情景模拟与真实预测分开，禁止把未经验证的情景称为治疗获益。显示模型版本、预测时点、范围、适用性、缺失数据及研究用途；未配置模型显示不可用，不生成虚假曲线。
### 5.5 FollowupRiskWorkspace
风险优先级、患者、触发原因、责任人、时限、通知/签收/处置状态、最近更新。高风险置顶，等级使用服务端明确排序。区分入队、通知、签收、处置、关闭；不将入队称为外部送达。AI 抽取原话与待确认字段分开；确认前不得显示为正式观测。关闭操作须遵守后端状态机，失败保留原状态。
### 5.6 EvidencePanel / ClinicalCopilot
建议、证据、患者事实、医生确认分区；证据显示标题、来源、版本、日期、引用定位及适用性。AI 输出标注待审核，提供查看依据、采纳/拒绝及原因记录；无证据、服务不可用或信息不足明确显示。禁止 AI 自动执行治疗或修改已审核计划。

## 7. 组件与工程目录（拟议，先核对现有结构）
front/src/styles/clinical-tokens.css（或合并现有全局 CSS，避免双 token 源）
front/src/components/ui/：现有 shadcn 基础组件
front/src/components/clinical/：PatientHeader、ClinicalMetric、RiskIndicator、StateSnapshot、EvidenceCard、ClinicalStatus
front/src/components/visualization/：PathwayGraph、PatientTimeline、LabTrendChart、StateEvolution、PredictionBand
front/src/components/ai/：ClinicalCopilot、EvidencePanel、AIRecommendation、HumanReview
front/src/lib/clinical-semantics.ts：服务端状态到视觉语义的映射，未知枚举安全降级
front/src/lib/chart-theme.ts：ECharts 主题、轴、网格、tooltip、图例
front/e2e/：复用现有 Playwright，增加视觉与交互用例
不重复封装已有组件，不引入新的全局状态库，不修改后端契约来迎合视觉设计。

## 8. 交互、数据与可访问性
每个异步组件提供 loading/empty/error/forbidden/unavailable/stale 状态；错误不回退 mock。保留数据来源、时间、版本、环境、权限。危险操作明确对象与后果，确认后等待后端成功；禁止对审批/激活/风险关闭做未经确认的乐观更新。键盘可达、焦点可见、弹窗焦点恢复、表格语义、图表替代文本与数据表；屏幕阅读器可识别状态变化。真实患者数据不进入视觉快照、前端日志或外部字体/CDN。所有演示截图使用合成数据。

## 10. 验收清单
- [ ] 统一 token，业务页面无散布的临床状态色硬编码。
- [ ] 1280×800、1440×900、1920×1080 下关键页面可用，200% 缩放核心操作可达。
- [ ] 关键文字/控件对比度测量通过，状态不只靠颜色。
- [ ] 路径选中、未选、UNKNOWN 与后端轨迹一致；支持等价列表。
- [ ] 时间轴、指标、预测正确表达缺失、单位、来源与时点。
- [ ] Server 模式无 mock 回退；未接入功能明确不可用。
- [ ] 高风险队列、审批及关闭操作不绕过业务约束。
- [ ] Playwright 截图基线采用合成数据，覆盖正常、空、失败、无权限及风险状态。
- [ ] 现有 build/typecheck、业务 E2E 无回归。
- [ ] 设计评审与临床人员可用性评审完成；不等同于临床验证。

本规范是视觉与工程设计提案，具体尺寸、目录、色值由实施团队核对现有源码后调整。未进行逐页视觉验收或独立测试，不宣称符合医疗监管或无障碍认证。
