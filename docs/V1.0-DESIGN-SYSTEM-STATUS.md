# HCC-CIP Design System V1.0 · 实施状态

## 已完成

### DS01 全局 Token 与 AppShell

- 统一浅色 canvas `#F7F8FA` / surface `#FFFFFF`
- 正文 `#18181B`，辅助文字 `#71717A`，边框 `#E4E4E7`
- 主操作 `#18181B`，品牌红 `#C63538` 小面积使用
- 临床语义色：完成/执行中/待处理/高风险/未知/AI 建议
- 图表 token 改为中性 + 语义色，不再使用旧海军蓝/绿色品牌色
- 焦点环 `#2563EB`，支持 `prefers-reduced-motion`
- 顶栏 52px；侧栏 216px / 折叠 56px；内容区 24px 间距
- 品牌 logo、侧栏导航、登录页改为 light surface；版本号统一 V0.6.1
- 页面标题 24/32px；正文 13–14px；表格行高约 44px
- 按钮默认 36px，紧凑 32px

### DS02 基础交互与语义

- 新增 `src/lib/clinical-semantics.ts`：状态到语义的安全映射，未知枚举降级为 UNKNOWN
- 新增 `ClinicalStatus` 组件
- 新增 `src/components/charts/chart-theme.ts`，统一图表颜色来源
- 成功/执行中/待处理/高风险/未知均保留文字与形状冗余标识

### DS05 时间轴与趋势图（完成基础版本）

- 新增 `PatientTimeline`：真实时间坐标、评估/检验检查/治疗执行/变异重评/随访结局泳道
- 支持全部 / 近 7 天 / 近 24h 范围切换
- 事件时间与录入时间分列；`recordedAt` 未提供时显示“未提供”，不伪造
- 提供等价表格视图；事件点击展示来源、操作人、事件时间
- 关键检验趋势改为真实时间轴（非等距分类轴）
- ALT / TBIL / AFP 支持图/表切换、参考区间、采集时间、来源与单位
- 明确缺测不绘制、不填零、单位不一致不直接连线

### DS03 患者详情与路径执行态（完成基础版本）

- 路径执行页增加三段状态条：当前阶段 / 关键决策 / 需要关注
- 路径检查器可折叠；画布聚焦当前/选中节点，避免整图缩得过小
- 新增“演示导览”5 步叙事：患者状态 → 路径执行 → 审批 → 任务 → 全貌
- 顶部演示导览为 demo 模式专属，Server 模式不显示 mock 叙事

- 患者详情新增 `StateSnapshot` 状态快照条：当前阶段、风险、完整度、快照时点、数据来源
- 风险语义独立映射：低/中/高/严重；未知风险不再显示为“未知/缺失”
- 患者详情、任务、变异、随访、规划、分析页已使用新 token
- PathwayGraph 增加 `not_selected` 视觉态：虚线、弱化、图例“未选路径”
- PathwayGraph 增加 `unknown` 视觉态：琥珀色虚线、UNKNOWN 标签、待补充提示
- 路径执行图增加“图 / 列表”等价视图，列表展示节点、阶段、状态、角色、时间约束、证据数
- 路径执行图默认缩放提高，节点接近 160px 可读宽度；仍支持适应画布
- 新增路径图/详情/时间轴/检验趋势/路径列表截图基线
- 登录、AppShell、来源标识、环境/SYNTHETIC 持续可见
- 视觉截图基线：`front/docs/preview/design-system-v1/`
- 尚未完成：预测区间、时间轴与检验/事件联动、双主题、全量键盘/对比度测量、视觉回归截图断言
