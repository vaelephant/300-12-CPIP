答

结论

杂乱不是信息太多，而是同一事实被说了三遍，再用彩色面板、字轨标签和卡片墙互相抢戏。Vercel 风格的本质是：一屏一个主角、灰阶扛层级、色只标状态、字比盒子重要。

  1. Vercel 产品面：近白/近黑底、Geist 系无衬线、发丝线、一个黑底主按钮、其余安静。
  2. 我们观测台：阶段轨 + 三色带 + Flow + A/B/C 三卡 + 展开区 + Inspector 叠在同一竖轴，每层都有 WORLD MODEL / FUTURE · COMPARE 这类字轨。
  3. 医疗不能照搬营销站，但应借它的克制规则；Fraunces 编辑风 + 青绿色氛围适合 Demo 海报，不适合日用临床面。
  4. 下一刀不是再加组件，而是删重复层、统一灰阶、对比改「一行表」而不是「三张卡」。

适用于视觉方向观测台/世界模型借鉴 Vercel 克制而非抄品牌

1

Vercel 到底在克制什么？

法则 {#vr}Vercel 怎么做我们现状改法
一屏一主角登录页只推一个 Continue抢戏画布、对比轨、Inspector 同权重竖轴只留「阶段轨 → 画布」；对比与详情进次层
灰阶分层黑字 / 灰字 / 发丝边吵青绿底带 + 多色边框同时喊面板一律白/浅灰；色只给 risk/active
字 > 盒子标题本身就是层级卡墙先画圆角卡再塞字对比用表格行，不是三张同构卡
少标签几乎不用 ALL-CAPS 眉题装饰WORLD MODEL CDSS · NOW 过密删字轨；需要时一句人话
一主操作一个实心黑按钮散路径图/CDSS/闸门并排抢工具条：左上下文，右一个「CDSS」
重复禁止同一数据只出现一次三遍情景在 Flow、三卡、Inspector 各说一遍选中后只在一侧详述

不是做成 Vercel 克隆

医疗界面要更高信息密度；借的是「冷静与唯一主角」，不是三角 Logo 或营销留白。密度可以高，嘈杂不可以。

按 Vercel 法则，竖轴应收成什么样？

图的结构
  • 一行上下文 · 一个 CDSS bar
  • 细阶段轨（无彩带标题） stages
  • 全宽 Past|Now|Future 画布 flow
  • 底栏或右抽屉：对比表 / 详情二选一 detail
  • bar → stages
  • stages → flow · 主角
  • flow → detail · 点选才展开
区域 {#calm}内容不做
顶栏陈志远 · 术前检查 · 46% + 按钮「CDSS」不要 WORLD MODEL 字轨、双按钮
阶段轨细进度条，选中微高亮不要大段 summary 卡片
画布唯一主角；Future 扇出即对比入口不要再叠三色大标题带
底/侧对比表一行一情景；点行展开前提/证据不要三张同构卡 + 下方再 Inspector
色默认墨与灰；超时/风险才红；推演用一条虚线不要整块青绿未来底
Future 对比形态现在Vercel 化
呈现卡墙三张圆角卡并排表三行表：情景 / 窗口 / 30d / 90d / 风险
选中卡下再开大面板一层表下行内展开，或右侧一列详情
与 Flow扇出节点 + 卡 + Inspector单源扇出点选 → 只驱动详情列

字体与色：怎么换才不「Demo 海报」？

Token {#tk}建议原因
正文字体单一无衬线（Geist / 系统 UI / 现有 Plex Sans 择一）双字体 + 衬线标题偏编辑杂志
数字等宽只用于数值与 ID，不用于章节眉题避免满屏 TRACKING 标签
底#FAFAFA 画布 · #FFF 面 · #EAEAEA 线对齐 Vercel 发丝线体系
墨#171717 主字 · #666 次字用灰阶分层，不用色块分层
语义色仅 risk / warn / ok；推演不用大面积青底色 = 状态，不是氛围
圆角统一 6–8px与 Vercel 控件一致，少「胶囊」

最该先删的三样

1. 满屏字轨眉题（FUTURE · COMPARE 等）。 2. A/B/C 三卡与 Flow 扇出 + Inspector 的三重复述。 3. Past/Now/Future 整条色带标题——改成画布内极淡分区或虚线即可。

5

建议落地顺序？

  1. 删重复层

    底栏只留「对比表」；去掉独立 Inspector 或合并进表的展开行。

  2. 灰阶化

    去掉 futureBand 大块着色；风险只用字色/小点。

  3. 顶栏一句人话

    换成患者·阶段·进度；CDSS 单按钮开抽屉。

  4. 字轨清零

    章节标题改句子或直接省略。

  5. 字体收敛

    观测台日用面去掉 Fraunces；衬线留给对外介绍页。
