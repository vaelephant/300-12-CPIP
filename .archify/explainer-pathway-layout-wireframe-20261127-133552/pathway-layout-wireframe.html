答

结论

路径实时视图应把路径图画布顶到首屏；身份与阶段只占一条 sticky 条，状态与决策贴在图上，不再叠卡片墙。

  1. 现状页头栈过厚：大标题、患者卡、两张状态卡压在画布之上，主面进屏太晚。
  2. After 把常驻壳层压成「顶栏 + 身份条 + 工具条」，侧栏深工作页默认收成 icon rail。
  3. 进度、阶段、决策只保留一处权威展示，消除 banner / 卡 / 轨上的重复数字。
  4. 本页对照范围仅限路径实时视图的垂直分区，不含工作台 KPI 与患者 Tab 细节。

改动顺序怎么落地？

  1. 并身份条

    去掉大标题块与患者卡；Meta 非关键字段进抽屉。

  2. 迁状态卡

    「当前阶段 / 关键决策」改为画布焦点与 Inspector。

  3. 收工具条

    常驻只留模式切换与视图；其余进溢出。

  4. 收侧栏

    路径图 / 世界模型 / 观测台进入时默认 icon rail。
