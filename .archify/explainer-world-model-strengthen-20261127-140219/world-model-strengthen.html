结论

先把世界模型做成可演示的临床决策面：Past 接真执行、Now 接阻断与 CDSS、Future 保持研究闸门；壳层学路径图「主面优先」，再谈引擎。

  1. 现状已有 Past|Now|Future 画布、CDSS 双向联动与激活闸门，但数据仍是 fixture。1
  2. 组件仍住在 dev/desgin/kit，却已挂进患者「观测台」——边界不清，难做产品化。2
  3. 与路径实时图、任务、检验未打通：同一阶段进度可能两套说法。
  4. Future 有 clinical_use=false 语义，但对比 A/B/C、证据追溯与「生成草稿」后的路径仍浅。

适用于世界模型观测台产品强化优先级不含真实计划引擎

图的结构

  • CDSS 行动列表 cdss
  • Past · Now · Future 画布 wm
  • 激活闸门 · 待审草稿 gate
  • 计划引擎 · 未接 engine
  • pathway → wm · 阶段应对齐
  • cdss → wm · 已双向定位

  1. 标准路径执行 ↗

    执行页 / 路径图已有；观测台阶段轨未共用同一数据源。

  2. CDSS 行动列表 ↗

    三条 fixture 行动可定位画布；缺任务/检验回写。

  3. Past · Now · Future 画布 ↗

    交互骨架完整；Past 未接任务事件，Future 节点过浅。

  4. 激活闸门 · 待审草稿 ↗

    闸门文案对；草稿未进入审核中心。

第一周先交付什么？

  1. 壳层主面化

    观测台复用 sticky 身份条与全高画布；CDSS/闸门进右侧抽屉。

  2. Past 接实例

    用现有 tasks / replay 快照填 WmPastEvent，阶段轨对齐 instance.currentStage。

  3. Now 接阻断

    nowBlockers / nowFacts 从缺失字段与超时任务派生，CDSS 条目跟 Now 同源。

  4. 闸门闭环 Demo

    「生成待审草稿」写入本地审核列表或跳转审核中心空态，仍标合成。

  5. 深链入口

    路径图工具条「观测台」· 观测台「打开路径图」，带 stage / nodeKey。

边界

本页建议停在「半真数据 + 闸门 Demo」。接生产计划引擎属于后置；未接引擎前对外话术保持「研究情景 · 待审草稿」。
